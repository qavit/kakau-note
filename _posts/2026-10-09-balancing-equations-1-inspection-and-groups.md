銅溶在稀硝酸裡，平衡後的係數是

$$\ce{3Cu + 8HNO3 -> 3Cu(NO3)2 + 2NO + 4H2O}$$

很多老師會建議學生直接背「3 比 8」。背下來當然省時間，但段考題目只要換一個金屬、換一種產物，背過的數字就派不上用場。

這個系列要處理的是：**遇到看不出來的反應式，要用什麼方法把係數算出來？**

## 平衡到底在平衡什麼？

平衡化學反應式（balancing chemical equation）根據的是**原子不滅**：反應前後，每一種元素的原子數相同。若反應式中有離子，還要加上**電荷守恆**：兩邊的總電荷相同。

能調整的只有**係數**，不能調整**下標**。為了湊氧原子把 $\ce{H2O}$ 改成 $\ce{H2O2}$，等於換成另一種物質。化學式決定「這是什麼物質」，係數決定「取多少份」。

> 平衡化學反應式 ＝ 只調整係數，讓每一種元素（以及電荷）在兩邊各自守恆。
{: .prompt-info }

## 方法一：觀察法要有順序

觀察法（inspection）不是亂試。順序對了，大部分反應式都能一路推完：

1. **先挑最複雜的分子**，把它的係數暫定為 1。
2. **先平衡只出現在一個反應物、一個生成物裡的元素**，每平衡一種，就會有新的係數被確定。
3. **H、O 和元素態物質（如 $\ce{O2}$、$\ce{Cl2}$）留到最後**：它們通常出現在很多物質裡，但元素態物質的係數可以隨意調整，不會牽動其他元素。
4. 過程中出現分數沒關係，最後整體乘上分母即可。

### 例 1：條件給一半的題目

> **龍騰版選修化學 I 第一章習題第 3 題（改寫）**：氯化亞鐵與硝酸鉀在鹽酸中反應，
>
> $$a\,\ce{FeCl2} + b\,\ce{KNO3} + c\,\ce{HCl} \ce{->} d\,\ce{FeCl3} + e\,\ce{KCl} + f\,\ce{X} + g\,\ce{H2O}$$
>
> 若 $b=1$、$d=3$，產物 X 是 $\ce{NH4Cl}$、$\ce{N2O}$、$\ce{NO}$、$\ce{N2O3}$、$\ce{NO2}$ 中的哪一個？

X 未知，看起來無從下手。但題目已給兩個係數，只要逐一守恆每種元素：

| 元素 | 守恆式 | 結果 |
|---|---|---|
| Fe | $a = d$ | $a = 3$ |
| K | $b = e$ | $e = 1$ |
| Cl | $2a + c = 3d + e$ | $6 + c = 10$，$c = 4$ |
| H | $c = 2g$（先假設 X 不含 H） | $g = 2$ |
| N | 左邊 1 個 N，全部進入 X | X 共含 1 個 N |
| O | 左邊 3 個 O，水用掉 2 個 | X 共含 1 個 O |

「$f$ 份 X」總共只有 1 個 N、1 個 O，所以 $f\,\ce{X} = \ce{NO}$，答案是 **(C) NO**：

$$\ce{3FeCl2 + KNO3 + 4HCl -> 3FeCl3 + KCl + NO + 2H2O}$$

最後驗算 H：左邊 4 個，右邊 $2\times 2 = 4$ 個。若 X 是 $\ce{NH4Cl}$，H 與 Cl 都會對不上，所以「X 不含 H」的假設也成立。

這題完全不需要氧化還原的知識：**未知的產物，可以靠原子收支把它的組成算出來。**

## 方法二：把原子團或氧化物當成一塊

如果某個原子團（$\ce{SO4}$、$\ce{NO3}$、$\ce{CO3}$、$\ce{PO4}$、$\ce{OH}$……）在反應前後**完整保留**，就把它當成一顆「大原子」來數，未知數會一下子變少。

進一步的技巧是：原子團雖然沒有完整保留，但可以**拆成相關的氧化物或氣體**：

$$\ce{CO3} = \ce{CO2} + \ce{O}, \qquad \ce{NO3} \text{（兩個）} \to \ce{N2O5} = \ce{2NO2} + \tfrac12\ce{O2}$$

碳酸鹽加熱放出 $\ce{CO2}$、硝酸鹽加熱放出 $\ce{NO2}$，都是這種拆法的化學直覺。

### 例 2：硝酸鉛加熱分解

$$\ce{Pb(NO3)2 -> PbO + NO2 + O2}$$

把 $\ce{Pb(NO3)2}$ 寫成 $\ce{PbO}\cdot\ce{N2O5}$（Pb、N、O 原子數都對得上：1、2、6），$\ce{PbO}$ 直接留下，剩下的 $\ce{N2O5}$ 拆成 $\ce{2NO2 + 1/2 O2}$。乘 2：

$$\ce{2Pb(NO3)2 -> 2PbO + 4NO2 + O2}$$

### 例 3：碳酸亞鐵在空氣中加熱

$$\ce{FeCO3 + O2 -> Fe2O3 + CO2}$$

$\ce{FeCO3} = \ce{FeO}\cdot\ce{CO2}$。$\ce{CO2}$ 整塊離開；真正要平衡的只有 $\ce{FeO}$ 變成 $\ce{Fe2O3}$：

$$\ce{2FeO + 1/2 O2 -> Fe2O3}$$

乘 2，再把 $\ce{CO2}$ 放回來：

$$\ce{4FeCO3 + O2 -> 2Fe2O3 + 4CO2}$$

### 例 4：磷的工業製備

$$\ce{Ca3(PO4)2 + SiO2 + C -> CaSiO3 + P4 + CO}$$

六種物質、五種元素，直接硬湊很痛苦。改用氧化物拆解：

- $\ce{Ca3(PO4)2} = 3\ce{CaO}\cdot\ce{P2O5}$
- 鹼性氧化物配酸性氧化物：$\ce{CaO + SiO2 -> CaSiO3}$，所以需要 3 份 $\ce{SiO2}$
- 剩下 $\ce{P2O5}$ 被碳奪走氧：$\ce{P2O5 + 5C -> 2P + 5CO}$

一份 $\ce{Ca3(PO4)2}$ 對應 $3\,\ce{SiO2}$、$5\,\ce{C}$、$3\,\ce{CaSiO3}$、$2\,\ce{P}$、$5\,\ce{CO}$。$\ce{P4}$ 要 4 個 P，所以乘 2：

$$\ce{2Ca3(PO4)2 + 6SiO2 + 10C -> 6CaSiO3 + P4 + 10CO}$$

### 例 5：水合物——綠礬受熱分解

水合物的結晶水（$\cdot n\ce{H2O}$）幾乎都是整塊跑出來的，先把它放一邊。

$$\ce{FeSO4*7H2O -> Fe2O3 + SO2 + SO3 + H2O}$$

拿掉結晶水，$\ce{FeSO4} = \ce{FeO}\cdot\ce{SO3}$。兩份 $\ce{FeO}$ 要變成 $\ce{Fe2O3}$ 需要多一個 O，這個 O 從其中一份 $\ce{SO3}$ 拿走，它就變成 $\ce{SO2}$：

$$2\,(\ce{FeO}\cdot\ce{SO3}) \ce{-> Fe2O3 + SO2 + SO3}$$

最後把 $2 \times 7 = 14$ 份結晶水放回來：

$$\ce{2FeSO4*7H2O -> Fe2O3 + SO2 + SO3 + 14H2O}$$

這題其實是氧化還原（Fe 被氧化、S 被還原），但「拆氧化物」的做法完全不用算氧化數。[第二篇]({% post_url 2026-10-09-balancing-equations-2-oxidation-numbers %})會用電子得失再驗算一次。

## 方法三：代數法——把係數設成未知數

觀察法推不下去時，最可靠的方法是**代數法**：每個係數設一個未知數，每種元素列一條守恆式，解聯立方程式。

### 例 6：硫化亞銅溶於硝酸

> **龍騰版選修化學 I 第一章習題第 4 題（改寫）**：
>
> $$a\,\ce{Cu2S} + b\,\ce{HNO3} \ce{->} c\,\ce{Cu(NO3)2} + d\,\ce{H2SO4} + e\,\ce{NO} + f\,\ce{H2O}$$
>
> 平衡後最簡單整數係數的總和是多少？

六個未知數，五種元素：

$$
\begin{aligned}
\text{Cu}&:\ 2a = c\\
\text{S}&:\ a = d\\
\text{N}&:\ b = 2c + e\\
\text{H}&:\ b = 2d + 2f\\
\text{O}&:\ 3b = 6c + 4d + e + f
\end{aligned}
$$

五條式子、六個未知數，所以可以**令其中一個為 1**（係數只代表比例）。令 $a = 1$，得 $c = 2$、$d = 1$，剩下：

$$
\begin{aligned}
b &= 4 + e\\
b &= 2 + 2f\\
3b &= 16 + e + f
\end{aligned}
$$

把 $e = b - 4$、$f = \dfrac{b-2}{2}$ 代入第三式：

$$3b = 16 + (b - 4) + \frac{b - 2}{2} \quad\Longrightarrow\quad b = \frac{22}{3}$$

於是 $e = \dfrac{10}{3}$、$f = \dfrac{8}{3}$。全部乘 3：

$$\ce{3Cu2S + 22HNO3 -> 6Cu(NO3)2 + 3H2SO4 + 10NO + 8H2O}$$

係數和 $3 + 22 + 6 + 3 + 10 + 8 = 52$，答案 **(D)**。

驗算 O：左邊 $22 \times 3 = 66$；右邊 $36 + 12 + 10 + 8 = 66$。

> **訣竅**：令哪個係數為 1，會影響計算量。優先選**能連鎖確定最多係數**的那一個（這題令 $a=1$ 立刻得到 $c$、$d$）。
{: .prompt-tip }

### 例 7：王水溶金——電荷也是一條方程式

> **龍騰版選修化學 I 第一章習題第 2 題（改寫）**：黃金溶於王水，
>
> $$\ce{Au + H+ + Cl- + NO3- -> AuCl4- + NO + H2O}$$
>
> 平衡後最簡單整數係數總和為何？

離子反應式除了元素守恆，還要**電荷守恆**。設係數依序為 $a,b,c,d,e,f,g$：

$$
\begin{aligned}
\text{Au}&:\ a = e\\
\text{Cl}&:\ c = 4e\\
\text{N}&:\ d = f\\
\text{O}&:\ 3d = f + g\\
\text{H}&:\ b = 2g\\
\text{電荷}&:\ b - c - d = -e
\end{aligned}
$$

令 $a = e = 1$，得 $c = 4$。由 N、O：$g = 2d$；由 H：$b = 4d$。代入電荷式：$4d - 4 - d = -1$，所以 $d = 1$。

$$\ce{Au + 4H+ + 4Cl- + NO3- -> AuCl4- + NO + 2H2O}$$

總和 $1+4+4+1+1+1+2 = 14$，答案 **(E)**。

少了電荷那一條式子，這題只靠原子收支解不出唯一答案。

## 回到開頭：銅與硝酸要不要背？

用代數法，濃、稀硝酸各算一次：

$$
\begin{aligned}
\text{濃硝酸}&:\quad \ce{Cu + 4HNO3 -> Cu(NO3)2 + 2NO2 + 2H2O}\\
\text{稀硝酸}&:\quad \ce{3Cu + 8HNO3 -> 3Cu(NO3)2 + 2NO + 4H2O}
\end{aligned}
$$

濃硝酸是 $1:4$，稀硝酸是 $3:8$。兩條式子差在哪裡？

**差在產物，不在係數。** 濃硝酸生成 $\ce{NO2}$、稀硝酸生成 $\ce{NO}$，這是化學事實，必須知道；但只要產物確定了，係數就由原子守恆唯一決定，不需要背。

把硝酸分成兩種角色，會看得更清楚：

| | 消耗的 $\ce{HNO3}$ | 留在 $\ce{Cu(NO3)2}$（只提供 $\ce{NO3-}$） | 被還原成氣體 |
|---|---|---|---|
| 濃硝酸（每 1 Cu） | 4 | 2 | 2（成 $\ce{NO2}$） |
| 稀硝酸（每 3 Cu） | 8 | 6 | 2（成 $\ce{NO}$） |

稀硝酸裡只有 $\dfrac{2}{8} = \dfrac14$ 的硝酸真正當氧化劑，其餘 $\ce{NO3-}$ 原封不動進入硝酸銅。這正是「原子團當成一塊」的觀點：**$\ce{Cu(NO3)2}$ 裡的硝酸根沒有參與反應。**

如果題目說生成的是 $\ce{NO}$ 和 $\ce{NO2}$ 的混合氣體呢？那時原子守恆本身就無法決定比例，必須由題目給更多條件。這是[第三篇]({% post_url 2026-10-09-balancing-equations-3-linear-algebra %})的主題。

## 總結

| 方法 | 適用時機 | 關鍵動作 |
|---|---|---|
| 觀察法 | 物質少、元素只出現在少數物質中 | 從最複雜的分子開始；H、O、元素態物質最後處理 |
| 原子團法 | 有完整保留的原子團、結晶水 | 原子團當成一顆大原子來數 |
| 氧化物拆解 | 含氧酸鹽分解、礦石冶煉 | $\ce{CO3 -> CO2 + O}$、$\ce{N2O5 -> 2NO2 + 1/2O2}$、$\ce{Ca3(PO4)2} = 3\ce{CaO}\cdot\ce{P2O5}$ |
| 代數法 | 任何反應式，尤其觀察法卡關時 | 每種元素（與電荷）一條式子，令一個係數為 1 |

- 能改的只有係數，下標代表物質本身。
- 離子反應式多一條電荷守恆。
- 產物是化學事實，係數是算出來的。
